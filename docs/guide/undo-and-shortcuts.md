# Undo and shortcuts

## Undo

**Edit → Undo** (Ctrl+Z) and **Redo** (Ctrl+Y on Windows, Ctrl+Shift+Z elsewhere) step through everything you've changed while the keep is open, one step at a time, in order. The menu names the step ("Undo Tag 3 items with 'Favorites'"), and the status bar says what was undone.

What can be undone:

- tagging and untagging; making, renaming, moving, merging, and deleting tags; colors, descriptions, aliases, and what a tag applies to;
- editing a field, an extra field, or a title; re-reading files;
- linking and unlinking files by hand; adding and removing related items; putting items in a project and taking them out; reordering authors;
- merging items, marking "not a duplicate", dismissing in Triage, deleting items;
- mapping and ignoring file keywords; saving, renaming, and deleting saved searches;
- the theme's commands that change items.

What can't: scans, changing Keep configuration, online lookups, and **Write to file…** (its backups are the way back). The history lasts until the keep closes (100 steps).

## Keyboard shortcuts

**Help → Keyboard shortcuts** (F1, or Ctrl+/) lists every key, with a box to find one. On a Mac, Ctrl is ⌘.

| Key | |
|---|---|
| F5 | Scan now |
| Ctrl+O | Open another keep |
| Ctrl+W | Close the keep |
| Ctrl+Z | Undo |
| Ctrl+Y (Windows), Ctrl+Shift+Z | Redo |
| Ctrl+T | Tag the selection (the cursor to the Tags panel) |
| Ctrl+S, Ctrl+Shift+S | Save search, Save search as |
| Alt+Left, Alt+Right | Back, Forward |
| Ctrl+Shift+A | Show the Activity panel |
| Ctrl+=, Ctrl+- | Bigger or smaller thumbnails |
| F1 | Keyboard shortcuts |

**In the results**

| Key | |
|---|---|
| Enter, double-click | Open the item's page (or its file, for items that open as files) |
| Ctrl+Enter | The other one: the file, or the page |
| Ctrl+F | The cursor to the search box |
| Ctrl+wheel | In a grid: bigger or smaller thumbnails |

**In the Add tag… box**

| Key | |
|---|---|
| Up, Down | Move through the suggested tags |
| Enter | Add the highlighted tag as a chip |
| Shift+Enter | Add it as a "but not" chip |
| Esc | Close the suggestions |

**In the Tags panel**

| Key | |
|---|---|
| Type | Filter the tags (from the tree too) |
| Down | From the filter into the tree |
| Enter | Apply the highlighted (or selected) tags to the selection |
| Shift+Enter | Remove them from the selection |
| Enter, with no match | Create the tag typed |
| Esc | Clear the filter, or go back to it from the tree |

**Editing a field:** Enter saves, Esc leaves it as it was. **In the navigation:** Up and Down move between pages, Left and Right fold or unfold a heading.
